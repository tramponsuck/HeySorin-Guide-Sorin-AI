# HeySorin Guide — Полное руководство по Sorin AI

**Sorin** — ваш персональный AI-агент для глобальных цифровых рынков от **Sahara AI**.

Исследование → Анализ → Мониторинг → Исполнение сделок — всё в одном чате.

- **Официальный сайт**: [heysorin.ai](https://heysorin.ai/)
- **Desktop App**: macOS (локальный запуск агентов)
- **Zero KYC** • **Non-custodial** • **Автономная торговля**

## ✨ Основные возможности

- Естественный язык для команд
- 20+ источников данных (on-chain, CEX, DEX, sentiment)
- Автономные агенты с guardrails
- Поддержка: Crypto, Stocks (tokenized), Prediction Markets, RWA
- Open Skills architecture + Sorin Skill (open-source)

## 🚀 Быстрый старт

1. Перейдите на [heysorin.ai](https://heysorin.ai/)
2. Войдите (Google / Wallet)
3. Подключите кошельки / API keys
4. Начните чат: «Проанализируй BTC» или «Составь портфель на 5000$»

**Полная документация** — в папке `/docs`.
